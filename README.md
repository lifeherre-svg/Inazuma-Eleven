# Golazo Tormenta

Juego de fútbol 5 contra 5 al estilo anime, con supertécnicas, hecho para jugar desde el navegador del móvil.

## Cómo jugar
- Abre `index.html` en el navegador (o actívalo con GitHub Pages: Settings → Pages → rama `main`, carpeta `/`).
- **Joystick**: toca y arrastra en la mitad izquierda de la pantalla.
- **Con balón**: TIRO, PASE (en la dirección del joystick) y SÚPER (supertécnica, cuesta 50 de espíritu).
- **Sin balón**: ENTRADA para robar y CAMBIAR de jugador.
- El espíritu sube con el tiempo, robando y pasando. Los porteros usan su técnica especial contra las supertécnicas.
- Teclado: flechas/WASD, J tiro, K pase, L súper, P pausa.
